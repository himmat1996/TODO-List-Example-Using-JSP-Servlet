# TODO-List-Example-Using-JSP-Servlet

A simple **TODO List** web application built with **Java Servlets** and **JSP (JavaServer Pages)**.
The project demonstrates the fundamentals of building a Java web application using the classic
Servlet + JSP stack, running on Apache Tomcat.

---

## Features

- Add new TODO tasks
- View the list of TODO tasks
- Mark tasks as completed / delete tasks
- Simple, clean JSP-based UI
- Uses JSTL for clean view rendering

---

## Tech Stack

- **Java** (Servlets API)
- **JSP** (JavaServer Pages)
- **JSTL** 1.2 (JSP Standard Tag Library)
- **Apache Tomcat 8.5.54** (Servlet container)
- **HTML / CSS** for the frontend
